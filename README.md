# Arm Kinematics (C++)

A C++ library for forward and inverse kinematics of serial robot arms,
ported from my MATLAB work on a UR5e. Built to learn modern C++.

## Status
🚧 In progress

## Features
- [ ] Vec3 / Matrix classes
- [ ] DH parameter setup
- [ ] Forward kinematics (2-DOF → 3-DOF → 6-DOF)
- [ ] Inverse kinematics
- [ ] Straight-line path following
- [ ] Results verified against MATLAB
